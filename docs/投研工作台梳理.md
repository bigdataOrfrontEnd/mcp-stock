## 一、两个项目如何拼成工作台

```
┌─ scratch-plugin（桌面独立项目，skill 层）──────────────────────────┐
│  cordis.yml（agent 预设）                                          │
│   ├─ stock-report-skills  挂载 skills/ 5 个报告模板（.md）          │
│   ├─ stock-data-mcp       stdio 拉起 uv run mcp-eastmoney          │
│   └─ stock-sdk-mcp        node 启动 stock-sdk-mcp（补充实时行情 65 工具）│
└──────────────┬────────────────────────────────────────────────────┘
               │ MCP 调用（工具命名空间 mcp__stock-data__* / mcp__stock-sdk__*）
┌─ mcp-eastmoney（本仓库，底座）─────────────────────────────────────┐
│  server.py — 33 个 Tool（行情/研究计算/推荐漏斗/情绪事件/基础/闭环）  │
│  ├─ data/      8 个数据客户端 + SQLite 19 张表（market_snapshot 已退役，quotes_daily 唯一真相源）（data/stock.db）      │
│  ├─ compute/   缠论/指标/因子/筹码/趋势/仓位/龙头（纯函数零网络）      │
│  ├─ recommend/ YAML 策略筛选 + run_pipeline 漏斗 + 龙头扫描          │
│  └─ refresh.py eod 14 步 / weekly / 12 个 CLI 编排任务               │
└────────────────────────────────────────────────────────────────────┘
```

- **skill 层**（scratch-plugin/skills/，5 个）：`stock-report-routing`（意图路由+展示规范）、`review`（收盘复盘）、`intraday`（盘中速览）、`morning`（早盘推荐，必须落表）、`analysis`（个股分析）。改 `.md` 即时生效。
- **底座层**（本仓库）：所有取数/计算/落表唯一入口，skill 里禁止用模型记忆补数。
- 环境变量 `STOCK_DB_PATH` 指向 `data/stock.db`；报告归档 `~/.dsh-stock/reports/`。
