# mcp-eastmoney 项目总览

> 个人 A 股智能投研工作台。基于 MCP 协议接入 DeepSeek Harness（dsh），
> 由三层架构 + DSH skill 层组成，支撑"复盘 / 盘中速览 / 早盘推荐 / 个股分析"四类报告
> 与"推荐 → 验证 → 归因 → 进化"的绩效飞轮。

---

## 一、架构（四层）

```
┌─ DSH skill 层（deepseek-harness/scratch-plugin/skills/）────────────┐
│  报告模板 ×4 + 意图路由：教模型"怎么想、怎么呈现"，模型进会话即见      │
└──────────────────────────────┬─────────────────────────────────────┘
                               │ 调用
┌─ MCP 工具层（server.py，17 个工具）─────────────────────────────────┐
│  查询 / 计算 / 落表 / 归档的唯一入口                                  │
├─ 计算层 compute/ ──────────────┤─ 数据层 data/ ─────────────────────┤
│  indicators.py  技术指标        │  db.py             SQLite 12张表   │
│  chan/          缠论完整引擎    │  baostock_client   基础/行业/K线    │
│  （纯函数，现算不落表）          │  akshare_client    概念/涨停池/F10 │
│                                │  eastmoney         实时（待用）     │
│                                │  codes             代码格式统一     │
├─ 编排层 refresh.py ─────────────┴────────────────────────────────────┤
│  basic/industry/daily/15min/concepts/ztpool/review/eod/weekly/dbinfo│
└─────────────────────────────────────────────────────────────────────┘
运行时资产 ~/.dsh-stock/：stock.db（数据）+ reports/（报告归档）+ skill/（预留）
```

## 二、数据层现状

**12 张表**（`~/.dsh-stock/stock.db`，WAL 模式）：

| 表 | 内容 | 更新 |
|---|---|---|
| stock_basic / stock_industry | 全市场身份 8840 / 证监会行业 5555 | 每周 |
| concepts / stock_concepts | 概念清单 375 / 成分快照（带日期） | 每日 |
| quotes_daily / quotes_15min | 日K（部分票回补至2015）/ 15分钟线 | 每日增量 |
| zt_pool | 涨停池快照（连板/炸板/封板时间） | 每日 |
| recommendations / recommendation_reviews | AI 推荐记录 / 后验绩效 | 推荐/eod 时 |
| watchlist / fetch_log / sector_hot_rank(空) | 辅助 | — |

**数据源分工**：Baostock（稳定，K线/基础/行业）｜东财 emweb+datacenter（F10板块/涨停池/人气，可用）｜东财 push2（实时，当前网络被断连，工具保留待用）｜同花顺（概念列表，成分仅部分快照）。

## 三、计算层

- `indicators.py`：MA/EMA/MACD/KDJ/RSI(Cutler)/BOLL/ATR + 自动信号（金叉死叉/超买超卖/均线排列/BOLL位置）
- `chan/`（完整版，自 stock-chanlun 移植）：包含关系合并→分型→笔→**线段**→中枢→背驰（MACD面积+RSI/KDJ共振）→**一二三类买卖点（含置信度/止损止盈）**→走势类型+支撑阻力+自然语言摘要。测试 `tests/test_chan.py` 4/4 通过

## 五、DSH skill 层（scratch-plugin/skills/）

| skill | 用途 |
|---|---|
| stock-report-routing | 意图路由：复盘/盘中/早盘/个股 → 选模板 |
| stock-report-review | 收盘复盘（大盘情绪/涨停梯队/概念/关注池体检/战绩/明日关注） |
| stock-report-intraday | 盘中速览（半屏：涨停面/热度/异动/一句话） |
| stock-report-morning | 早盘推荐（候选漏斗→≤3条→**必须落表**） |
| stock-report-analysis | 个股分析（画像/概念/技术面/缠论/量价/判断） |

挂载：cordis.yml 中 `dsh-skill-filesystem`（customSkillDirs → 插件 skills 目录）+ `dsh-mcp-client`（stdio 拉起 `uv run mcp-eastmoney`）。改 skill 文件即时生效；改 cordis.yml 需重启 dsh web 并新建会话。

## 六、推荐飞轮（阶段一已落地，阶段二待数据积累）

```
早盘推荐(morning skill) → save_recommendation 落表(带skill_version)
  → eod 每日自动验证(T+1/3/5收益/回撤, 到期终评)
  → get_recommendation_stats 归因(style/concept/confidence/skill_version)
  → (阶段二) AI 修订方法论进 skill → 版本对比 → 飞轮
```
防跑偏：归因 <5 条样本不结论；修订需引用绩效依据。
