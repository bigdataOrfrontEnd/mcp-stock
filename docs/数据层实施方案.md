## 目标架构（改造后的项目结构）

```
src/mcp_eastmoney/
├── server.py            # MCP 工具注册（现有 + 新增数据层工具）
├── eastmoney.py         # 东财实时客户端（现有，保留不动，负责"问一下就拿"）
├── baostock_client.py   # 【新增】Baostock：基础信息/行业/日K/15分钟K
├── akshare_client.py    # 【新增】AkShare：概念板块列表/成分股/热榜
├── db.py                # 【新增】SQLite：建表/upsert/查询（唯一落库入口）
├── codes.py             # 【新增】代码格式统一（6位码 ↔ sh.600519 ↔ secid）
└── refresh.py           # 【新增】定时刷新脚本：python -m mcp_eastmoney.refresh <task>
```

**职责边界**（重要，防止越写越乱）：

| 模块 | 只做 | 不做 |
|---|---|---|
| `eastmoney.py` | 实时查询（不落库） | 落库、历史序列 |
| `baostock_client.py` | 稳定历史数据拉取（返回 DataFrame/dict） | 落库 |
| `akshare_client.py` | 概念/热榜拉取 | 落库 |
| `db.py` | 全部落库与查询（唯一写库入口） | 网络请求 |
| `refresh.py` | 编排：调 client → 调 db | 业务逻辑 |

## Step 1：Baostock 客户端（1 天）

`baostock_client.py`，三个方法 + 四个硬性细节：

```python
import asyncio, baostock as bs, pandas as pd

def _rs_to_df(rs) -> pd.DataFrame:
    """pandas 2.0+ 兼容：必须手动收集，rs.get_data() 会崩"""
    rows = []
    while (rs.error_code == "0") and rs.next():
        rows.append(rs.get_row_data())
    return pd.DataFrame(rows, columns=rs.fields)

def _run(fn):
    """每次调用独立 login/logout（Baostock 非线程安全的规避方式）+ 线程池包装"""
    def _sync():
        lg = bs.login()
        if lg.error_code != "0":
            raise RuntimeError(f"baostock login failed: {lg.error_msg}")
        try:
            return fn()
        finally:
            bs.logout()
    return asyncio.to_thread(_sync)

async def query_stock_basic(code: str | None = None) -> pd.DataFrame: ...
async def query_stock_industry(code: str | None = None) -> pd.DataFrame: ...

async def query_kline(code: str, frequency: str = "d",
                      start: str = "2024-01-01", end: str | None = None) -> pd.DataFrame:
    """frequency: 'd' 日K / '15' 15分钟线。
    日K fields: date,code,open,high,low,close,preclose,volume,amount,turn,tradestatus,pctChg
    15min fields: time,code,open,high,low,close,volume,amount,adjustflag
    返回全部为字符串 → db 层落库前做类型转换
    """
```

**四个必须处理的坑（前面踩过/查过的）**：
1. pandas 2.0+ 不能用 `rs.get_data()` → 手动收集（上面已写）
2. 全字段是字符串 → 统一一个 `_num()` 转换函数，空串/`None` 转 NULL
3. 非线程安全 → 每次调用独立 login/logout + `asyncio.to_thread`（同步库不包装会阻塞 MCP 事件循环）
4. 15 分钟线回溯窗口只有约几个月 → 日 K 的 `start` 可以给到 `"2015-01-01"`，15 分钟线只拉当日/近日

**验收**（独立冒烟，不进 MCP）：


**增量逻辑（daily 的关键）**：拉取前先 `get_last_trade_date(code)`，`start = 最后日期 + 1天`；为空则从 `2015-01-01` 全量回补。避免每次都拉全历史。

**单只失败不阻断**：

```python
def refresh_daily(codes: list[str], days: int = 60) -> dict:
    results = {}
    for code in codes:
        try:
            df = asyncio.run(bc.query_kline(to_bs(code), "d", start=_inc_start(code)))
            n = db.upsert_klines_daily(df)
            results[code] = f"ok({n})"
        except Exception as e:
            results[code] = f"failed: {e}"      # 记录，继续下一只
        finally:
            db.log_fetch("daily", "baostock", "success" if ... else "failed", ...)
    return {"updated": results, "total": len(codes)}
```

## Step 3：概念板块 + 热度（1~2 天）

`akshare_client.py`（注意全部 `asyncio.to_thread` 包装）：

```python
import akshare as ak

async def concept_list() -> pd.DataFrame:
    """东财概念板块列表: ak.stock_board_concept_name_em()
       列: 排名,板块名称,板块代码,最新价,涨跌幅,..."""
```

`refresh_concepts()` 编排要点：

1. 拉 `concept_list()` → upsert `concepts` 表
2. **逐个概念拉成分股**：全量约 400+ 概念，一次全拉很慢且易被限。分两档：
   - 默认只刷**热度/涨跌幅 Top 50** 的概念（覆盖新闻场景足够）
   - `--all` 才全量刷
3. 每个概念 upsert 当日快照到 `stock_concepts`（`snapshot_date = 今日`）
4. 概念间加 `time.sleep(0.5)` 限速，失败记 fetch_log 继续

## 里程碑与顺序总结

| 步骤 | 产出 | 依赖 | 验收命令 |
|---|---|---|---|
| 0 | db.py 骨架 + 9 表 DDL + 依赖 | 无 | `.tables` 见 9 表 |
